🤔 DARI SATU KE BANYAK FITUR

Di Regresi Linear Sederhana (SLR), kita hanya punya satu fitur x untuk memprediksi y. Tapi di dunia nyata, hampir semua fenomena dipengaruhi oleh banyak faktor sekaligus.

Contoh: harga rumah tidak hanya ditentukan luas bangunan saja, tapi juga jarak ke pusat kota, jumlah kamar tidur, tahun dibangun, dll.

SLR — 1 Fitur

$$\hat{y} = b_0 + b_1 x_1$$

Garis lurus di ruang 2D.
Hanya 1 predictor.

MLR — Banyak Fitur

$$\hat{y} = b_0 + b_1 x_1 + b_2 x_2 + \cdots + b_p x_p$$

Hyperplane di ruang (p+1) dimensi.
p predictor sekaligus.

🏠 ANALOGI NYATA — HARGA RUMAH

Bayangkan kamu ingin prediksi harga rumah. Dengan SLR kamu pakai luas saja:

SLR: Harga = 2.1 × Luas + 40  →  MSE = —

Tapi rumah yang sama bisa jauh berbeda harganya karena lokasi! Dengan MLR kita tambahkan jarak ke pusat kota sebagai fitur ke-2:

MLR: Harga = b₀ + b₁×Luas + b₂×Jarak  →  MSE = —  (-— lebih baik!)
📉 SLR vs MLR — PERBANDINGAN AKURASI

Kuning = SLR (hanya luas)  |  Biru = MLR (luas + jarak, x2 ditetapkan di rata-rata)

📌 KAPAN PAKAI MLR?
✅
Ada beberapa fitur yang diduga mempengaruhi target secara simultan
✅
Ingin mengetahui kontribusi masing-masing fitur sambil mengontrol fitur lain
✅
Hubungan antara fitur dan target linear (atau bisa dilinearkan)
⚠️
Hati-hati multikolinearitas: jika fitur-fitur saling berkorelasi tinggi, estimasi koefisien jadi tidak stabil
📐 PERSAMAAN UMUM MLR

Model MLR dengan p fitur ditulis:

PERSAMAAN MLR
$$\hat{y} = b_0 + b_1 x_1 + b_2 x_2 + \cdots + b_p x_p = b_0 + \sum_{j=1}^{p} b_j x_j$$
  • 🔵 $b_0$ = intercept (nilai ŷ saat semua $x_j = 0$)
  • 🟣 $b_j$ = koefisien fitur ke-j (efek parsial: perubahan ŷ per +1 unit $x_j$, saat fitur lain tetap)
  • 🟢 $x_j$ = nilai fitur ke-j
  • 📌 p = jumlah fitur (predictor)
🔢 NOTASI MATRIX — BENTUK KOMPAK

Daripada menulis p persamaan terpisah, kita pakai notasi matrix yang jauh lebih ringkas:

BENTUK MATRIX
$$\hat{\mathbf{y}} = \mathbf{X}\boldsymbol{\beta}$$
Di mana: $$\mathbf{X} = \begin{bmatrix}1 & x_{11} & x_{12} & \cdots & x_{1p}\\1 & x_{21} & x_{22} & \cdots & x_{2p}\\\vdots & \vdots & \vdots & \ddots & \vdots\\1 & x_{n1} & x_{n2} & \cdots & x_{np}\end{bmatrix}, \quad \boldsymbol{\beta} = \begin{bmatrix}b_0\\b_1\\b_2\\\vdots\\b_p\end{bmatrix}$$

X = design matrix (n×(p+1))  |  Kolom pertama semua 1 (untuk intercept b₀)  |  β = vektor koefisien ((p+1)×1)

🔑 INTERPRETASI KOEFISIEN — KUNCI PENTING
Ceteris Paribus: Koefisien $b_j$ mengukur efek perubahan $x_j$ terhadap $\hat{y}$ sambil menganggap semua fitur lain tetap konstan. Inilah perbedaan fundamental MLR vs SLR.
KoefisienNilai (contoh)Interpretasi
$b_0$ (intercept)50.2Harga prediksi (juta) jika luas=0 dan jarak=0 (teoritis)
$b_1$ (luas)+2.47Setiap tambah 1 m², harga naik 2.47 juta — jarak dianggap tetap
$b_2$ (jarak)-3.21Setiap tambah 1 km, harga turun 3.21 juta — luas dianggap tetap
⚠️ STANDARDIZED COEFFICIENTS

Raw coefficients tidak bisa langsung dibandingkan jika satuan fitur berbeda (m² vs km). Untuk membandingkan kekuatan relatif setiap fitur, gunakan standardized coefficients (beta coefficients):

$$\beta_j^* = b_j \cdot \frac{SD(x_j)}{SD(y)}$$

Feature scaling (standardisasi) juga membantu gradient descent konvergen lebih cepat karena semua fitur punya skala yang sama. Lihat visualisasi di bawah:

📋 ASUMSI MLR — GAUSS-MARKOV THEOREM

OLS estimator adalah BLUE (Best Linear Unbiased Estimator) jika asumsi berikut terpenuhi. Asumsi ini wajib diperiksa setelah model difit!

1️⃣
Linearitas — hubungan antara fitur dan target memang linear.
Cek: scatter plot residual vs fitted. Jika ada pola kurva → tidak linear.
2️⃣
Independensi Residual — error antar observasi tidak saling berkorelasi.
Cek: Durbin-Watson test. Penting untuk data time series.
3️⃣
Homoscedasticity — variansi error konstan untuk semua nilai fitted.
Cek: scale-location plot. Jika ada corong/kerucut → heteroscedastic.
4️⃣
Normalitas Residual — error terdistribusi normal $e_i \sim \mathcal{N}(0, \sigma^2)$.
Cek: Q-Q plot. Titik harus mendekati garis diagonal lurus.
5️⃣
Tidak Ada Multikolinearitas — fitur-fitur tidak berkorelasi terlalu tinggi satu sama lain.
Cek: VIF (Variance Inflation Factor). VIF > 10 = masalah serius, VIF > 5 = perlu perhatian.
6️⃣
Tidak Ada Outlier Ekstrem — observasi ekstrem bisa mendistorsi koefisien.
Cek: Cook's Distance, leverage points.
Tips untuk Pemula: Asumsi bukan syarat mutlak sebelum fitting — fit dulu modelnya, baru periksa asumsi dari residualnya. Jika asumsi dilanggar, ada cara-cara untuk memperbaikinya (transformasi data, robust regression, dll).
📐 ORDINARY LEAST SQUARES — SOLUSI MATRIX

Tujuan OLS: cari β yang meminimalkan total kuadrat residual. Dengan notasi matrix, ini sangat elegan.

DERIVASI OLS — NOTASI MATRIX
1 / 7
1
Fungsi cost dalam notasi matrix
$$J(\boldsymbol{\beta}) = \|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 = (\mathbf{y} - \mathbf{X}\boldsymbol{\beta})^T(\mathbf{y} - \mathbf{X}\boldsymbol{\beta})$$
||·||² adalah norma Euclidean kuadrat — sama dengan menjumlahkan semua residual kuadrat. Notasi ini setara dengan MSE × n.
2
Ekspansi kuadratik
$$J(\boldsymbol{\beta}) = \mathbf{y}^T\mathbf{y} - 2\boldsymbol{\beta}^T\mathbf{X}^T\mathbf{y} + \boldsymbol{\beta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}$$
Ekspansi $(a-b)^T(a-b) = a^Ta - 2b^Ta + b^Tb$ dengan $a=\mathbf{y}$, $b=\mathbf{X}\boldsymbol{\beta}$. Gunakan sifat transpose: $(AB)^T = B^TA^T$.
3
Turunan terhadap β (gradient matrix)
$$\frac{\partial J}{\partial \boldsymbol{\beta}} = -2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}$$
Aturan turunan matrix: $\frac{\partial}{\partial\beta}(\beta^T A y) = Ay$ dan $\frac{\partial}{\partial\beta}(\beta^T A \beta) = 2A\beta$ jika A simetris.
4
Set gradient = 0 (syarat minimum)
$$-2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = \mathbf{0}$$
$$\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = \mathbf{X}^T\mathbf{y}$$
Ini disebut Normal Equations — sistem p+1 persamaan linear untuk p+1 unknown (β₀, β₁, ..., βₚ).
5
Verifikasi ini adalah minimum (bukan maksimum)
$$\frac{\partial^2 J}{\partial \boldsymbol{\beta}^2} = 2\mathbf{X}^T\mathbf{X}$$
$\mathbf{X}^T\mathbf{X}$ adalah matriks positive semi-definite (semua eigenvalue ≥ 0). Jika X full rank → positive definite → J convex → titik kritis adalah minimum global unik.
6
Selesaikan Normal Equations
$$\hat{\boldsymbol{\beta}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$$
Syarat: $\mathbf{X}^T\mathbf{X}$ harus invertible (full rank). Jika tidak invertible → ada multikolinearitas sempurna di antara fitur-fitur.
7 ✓
✅ SOLUSI OLS LENGKAP
$$\boxed{\hat{\boldsymbol{\beta}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}}$$
Ini adalah solusi closed-form yang memberikan koefisien optimal secara analitik!
Kompleksitas komputasi: O(p²n + p³) — untuk p besar, lebih efisien pakai iterative solvers.

⚠️ ADJUSTED R² — KENAPA PENTING?

Masalah dengan R² biasa: R² selalu naik jika kita tambah fitur baru, bahkan fitur acak yang tidak relevan sekalipun! Ini bisa membuat model terlihat lebih baik padahal tidak.

ADJUSTED R²
$$R^2_{adj} = 1 - \frac{(1-R^2)(n-1)}{n-p-1}$$
n = jumlah observasi  |  p = jumlah fitur
Adjusted R² memberikan penalti untuk setiap fitur tambahan. Hanya naik jika fitur baru benar-benar meningkatkan model melebihi penaltinya.
Rule of thumb: Jika $R^2_{adj}$ turun saat kamu tambah fitur baru → fitur itu tidak berguna, hapus saja!

📚 OVERFITTING VS UNDERFITTING

Overfitting

Model terlalu kompleks (terlalu banyak fitur) — hafal data training tapi buruk di data baru. R² tinggi di training, tapi buruk di test set.

Solusi: Regularisasi (Ridge/Lasso) Cross-validation Kurangi fitur

Underfitting

Model terlalu sederhana — tidak bisa menangkap pola dalam data. R² rendah di training dan test set.

Solusi: Tambah fitur relevan Feature engineering Model lebih kompleks
