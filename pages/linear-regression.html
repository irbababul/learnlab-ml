🎯 APA ITU REGRESI LINEAR?

Regresi Linear adalah algoritma supervised learning paling mendasar. Tujuannya sederhana: mencari garis lurus terbaik yang paling mendekati data.

Kata "terbaik" artinya garis yang meminimalkan total jarak kuadrat antara titik data dan garis tersebut. Jarak ini kita sebut residual.

Residual eᵢ = yᵢ − ŷᵢ

Kotak merah = eᵢ² yang harus diminimalkan

Efek Slope b₁

b₁ menentukan kemiringan — animasi menunjukkan perubahan real-time

🌍 ANALOGI NYATA

Kamu ingin prediksi nilai ujian berdasarkan jam belajar. Data menunjukkan pola: semakin banyak belajar → semakin tinggi nilai. Regresi Linear menemukan garis ŷ = b₁·x + b₀ yang paling "pas" dengan pola ini.

📐 PERSAMAAN MODEL

Model regresi linear sederhana ditulis sebagai:

PERSAMAAN GARIS
$$\hat{y} = b_0 + b_1 \cdot x$$
  • 🔵 $b_0$ = intercept (titik potong sumbu Y)
  • 🟣 $b_1$ = slope (kemiringan garis)
  • 🟢 $\hat{y}$ = nilai prediksi untuk input $x$
Efek b₀ (Intercept)

b₀ menggeser garis naik/turun tanpa mengubah kemiringan

Efek b₁ (Slope)

b₁ mengubah sudut kemiringan garis

🔢 INTERPRETASI NUMERIK

Contoh: Model prediksi harga rumah menghasilkan ŷ = 50 + 3.5·x (x = luas m², y = harga juta Rp)

• $b_0 = 50$ → harga dasar tanpa luas apapun adalah 50 juta (konstanta)
• $b_1 = 3.5$ → setiap tambah 1 m², harga naik 3.5 juta
• Prediksi untuk x = 80 m²: $\hat{y} = 50 + 3.5 \times 80 = 330$ juta Rp

📊 ASUMSI MODEL
1️⃣
Linearitas — hubungan antara X dan Y benar-benar linear
2️⃣
Independensi — observasi tidak saling mempengaruhi
3️⃣
Homoskedastisitas — variansi residual konstan di semua X
4️⃣
Normalitas Residual — error terdistribusi normal $\sim \mathcal{N}(0, \sigma^2)$
Distribusi Residual (harus mendekati normal)

Kurva biru = distribusi normal ideal; jika model baik, histogram residual menyerupai kurva ini

❓ KENAPA BUTUH COST FUNCTION?

Ada tak terhingga garis yang bisa kita gambar melalui data. Cost function memberikan satu angka yang mengukur seberapa buruk suatu garis. Tujuan training = mencari b₀ dan b₁ yang membuat angka ini sekecil mungkin.

LANGKAH 1 — Error Satu Titik Data
RESIDUAL
$$e_i = y_i - \hat{y}_i = y_i - (b_0 + b_1 x_i)$$

$e_i > 0$ → prediksi terlalu rendah  |  $e_i < 0$ → prediksi terlalu tinggi  |  $e_i = 0$ → prediksi sempurna

LANGKAH 2 — Kenapa Error Dikuadratkan?

Kalau langsung dijumlahkan: error positif dan negatif bisa saling meniadakan → $\sum e_i \approx 0$ meski prediksi jelek.

SQUARED ERROR
$$e_i^2 = (y_i - (b_0 + b_1 x_i))^2$$

Kuadrat memastikan: ✅ semua error positif   ✅ error besar dapat hukuman lebih besar (outlier sensitif)   ✅ differentiable (bisa diturunkan untuk GD)

LANGKAH 3 — Rata-Ratakan Semua → MSE
MEAN SQUARED ERROR
$$J(b_0, b_1) = \frac{1}{n}\sum_{i=1}^{n}(y_i - (b_0 + b_1 x_i))^2$$
$n$ = jumlah data  |  $J$ = cost (makin kecil makin baik)  |  Tujuan: cari $(b_0^*, b_1^*)$ yang meminimalkan $J$
J sebagai fungsi b₀ (b₁ tetap) — Parabola!

Titik putih bergerak = nilai J untuk berbagai b₀  |  Titik hijau = minimum  |  MSE selalu berbentuk parabola (convex) → ada satu minimum global

💡 SIFAT PENTING MSE
Convex — hanya satu minimum global
Differentiable — bisa dioptimasi dengan GD
Sensitif Outlier — error besar dikuadratkan
Satuan = Y² — susah diinterpretasi langsung
📐 ORDINARY LEAST SQUARES — SOLUSI CLOSED-FORM

OLS menemukan b₀ dan b₁ secara analitik — tanpa iterasi. Caranya: ambil turunan parsial J terhadap setiap parameter, set = 0, lalu selesaikan.

TURUNAN OLS — LANGKAH DEMI LANGKAH
1 / 7
1
Fungsi cost yang akan diminimalkan
$$J(b_0, b_1) = \frac{1}{n}\sum_{i=1}^{n}(y_i - b_0 - b_1 x_i)^2$$
Kita punya dua unknown: b₀ dan b₁. Untuk menemukan minimum, kita perlu dua persamaan.
2
Turunan parsial terhadap b₀ (set = 0)
$$\frac{\partial J}{\partial b_0} = \frac{-2}{n}\sum_{i=1}^{n}(y_i - b_0 - b_1 x_i) = 0$$
Chain rule: turunan $(u)^2$ = $2u \cdot u'$, dan turunan $(y_i - b_0 - b_1 x_i)$ terhadap $b_0$ = $-1$.
3
Sederhanakan → rumus b₀
$$\sum y_i = n b_0 + b_1 \sum x_i \quad\Rightarrow\quad \boxed{b_0 = \bar{y} - b_1 \bar{x}}$$
$\bar{x} = \frac{1}{n}\sum x_i$ dan $\bar{y} = \frac{1}{n}\sum y_i$ adalah rata-rata. b₀ tergantung nilai b₁.
4
Turunan parsial terhadap b₁ (set = 0)
$$\frac{\partial J}{\partial b_1} = \frac{-2}{n}\sum_{i=1}^{n} x_i(y_i - b_0 - b_1 x_i) = 0$$
Turunan $(y_i - b_0 - b_1 x_i)$ terhadap $b_1$ = $-x_i$ → hasilnya $-2x_i \cdot \text{residual}$.
5
Substitusi b₀ = ȳ − b₁x̄ ke persamaan b₁
$$\sum x_i(y_i - (\bar{y} - b_1\bar{x}) - b_1 x_i) = 0$$
$$\sum x_i(y_i - \bar{y}) = b_1\sum x_i(x_i - \bar{x})$$
Substitusi untuk menghilangkan b₀, sehingga hanya tersisa satu unknown: b₁.
6
Gunakan identitas aljabar statistik
$$\sum x_i(y_i-\bar{y}) = \sum(x_i-\bar{x})(y_i-\bar{y}) \quad\text{dan}\quad \sum x_i(x_i-\bar{x}) = \sum(x_i-\bar{x})^2$$
Identitas ini valid karena $\sum x_i \cdot \bar{y} = n\bar{x}\bar{y}$ dan $\sum \bar{x}(y_i-\bar{y}) = \bar{x}\sum(y_i-\bar{y}) = 0$.
7 ✓
✅ SOLUSI AKHIR OLS
$$\boxed{b_1 = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2} = \frac{\text{Cov}(X,Y)}{\text{Var}(X)}}$$
$$\boxed{b_0 = \bar{y} - b_1 \bar{x}}$$
Pembilang = kovarians X dan Y  |  Penyebut = variansi X.
Ini solusi closed-form — langsung hitung tanpa iterasi!
⛷️ GRADIENT DESCENT — SOLUSI ITERATIF

Gradient Descent menemukan minimum J secara bertahap — cocok untuk model kompleks yang tidak punya solusi closed-form. Bayangkan: kamu di bukit berkabut, selalu melangkah ke arah yang paling menurun.

DERIVASI GRADIENT DESCENT
1 / 6
1
Mulai dari nilai awal sembarang
$$b_0^{(0)} = 0, \quad b_1^{(0)} = 0 \quad \text{(atau random kecil)}$$
GD dimulai dari titik mana saja di permukaan J. Karena J convex, semua titik awal akan konvergen ke minimum yang sama.
2
Hitung gradient — arah naik tercepat
$$\frac{\partial J}{\partial b_0} = \frac{-2}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i) = \frac{-2}{n}\sum e_i$$
$$\frac{\partial J}{\partial b_1} = \frac{-2}{n}\sum_{i=1}^{n}x_i(y_i - \hat{y}_i) = \frac{-2}{n}\sum x_i e_i$$
Gradient = vektor turunan parsial. Arahnya menunjuk ke tempat J naik paling cepat dari posisi saat ini.
3
Update rule — bergerak berlawanan gradient
$$b_0 \leftarrow b_0 - \alpha \cdot \frac{\partial J}{\partial b_0}$$
$$b_1 \leftarrow b_1 - \alpha \cdot \frac{\partial J}{\partial b_1}$$
Tanda minus → bergerak berlawanan arah naik = menuruni bukit. $\alpha$ (learning rate) = panjang langkah.
4
Substitusi gradient yang sudah dihitung
$$b_0 \leftarrow b_0 + \frac{2\alpha}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)$$
$$b_1 \leftarrow b_1 + \frac{2\alpha}{n}\sum_{i=1}^{n}x_i(y_i - \hat{y}_i)$$
Perhatikan tanda: update bergerak searah dengan rata-rata residual (error yang tersisa).
5
Efek learning rate α
$\alpha$ terlalu kecil → konvergen sangat lambat (banyak iterasi)
$\alpha$ tepat → konvergen efisien menuju minimum
$\alpha$ terlalu besar → overshoot, bisa diverge (J malah naik!)
6 ✓
✅ ALGORITMA LENGKAP GD
INISIALISASI b₀ = 0, b₁ = 0
ULANGI sampai konvergen:
1. Hitung ŷᵢ = b₀ + b₁xᵢ untuk semua i
2. Hitung ∂J/∂b₀ dan ∂J/∂b₁
3. Update b₀ dan b₁ secara simultan
4. Hitung J baru — jika ΔJ < ε, berhenti
Konvergen jika J tidak berubah signifikan antar iterasi. Lihat Tab 8 untuk visualisasi interaktif!

1️⃣ MSE — MEAN SQUARED ERROR
$$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$
✅ Differentiable → cocok untuk GD ❌ Satuan = Y² → susah diinterpretasi ❌ Sensitif outlier 📌 Range: [0, ∞)
2️⃣ RMSE — ROOT MEAN SQUARED ERROR
$$RMSE = \sqrt{MSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$
✅ Satuan sama dengan Y → mudah diinterpretasi ❌ Masih sensitif outlier 📌 RMSE = 5 berarti rata-rata salah ~5 unit Y
3️⃣ MAE — MEAN ABSOLUTE ERROR
$$MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$$
✅ Robust terhadap outlier ✅ Interpretasi paling intuitif ❌ Tidak differentiable di 0 → butuh Huber loss untuk GD 📌 MAE = 3 berarti rata-rata salah 3 unit
4️⃣ R² — KOEFISIEN DETERMINASI
$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$
✅ Skala 0–1 yang intuitif 📌 R²=1: model sempurna | R²=0: sama seperti tebak rata-rata | R²<0: model lebih buruk dari rata-rata! 📌 "Model menjelaskan X% variansi data"
R² Visual: SS_res vs SS_tot
0.85

Merah = SS_res (error ke garis). Oranye = SS_tot (error ke rata-rata). R² = 1 − SS_res/SS_tot

5️⃣ MAPE — MEAN ABSOLUTE PERCENTAGE ERROR
$$MAPE = \frac{100\%}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right|$$
✅ Skala persentase → mudah dikomunikasikan ke non-teknis ❌ Undefined jika yᵢ = 0 ❌ Asymmetric — over-prediksi dan under-prediksi dihukum berbeda 📌 MAPE = 10% berarti rata-rata salah 10% dari nilai aktual

🎉 HASIL QUIZ

📉 LANGKAH 1 — OPTIMASI 1 PARAMETER

Sebelum bermain dengan 2 parameter sekaligus, mulai dari yang sederhana: tetapkan b₀ (intercept), dan ubah hanya b₁ (slope). Grafik kiri menunjukkan bagaimana nilai J (MSE) berubah seiring perubahan b₁ — berbentuk parabola. Titik terbawah parabola adalah nilai b₁ optimal untuk b₀ tersebut.

Panah biru = arah gradient (∂J/∂b₁). Gradient Descent akan bergerak berlawanan arah panah.

🔑 KONSEP KUNCI — MENGAPA PARABOLA?

MSE = rata-rata (y − b₁x − b₀)². Jika b₀ tetap, ini adalah fungsi kuadrat terhadap b₁:

$$J(b_1) = \frac{1}{n}\sum_{i=1}^{n}(y_i - b_0 - b_1 x_i)^2 = A \cdot b_1^2 + B \cdot b_1 + C$$

di mana $A = \frac{1}{n}\sum x_i^2 > 0$ → selalu convex (cembung ke atas) → selalu ada 1 minimum global. Minimum dicapai saat $\frac{dJ}{db_1} = 0$, yaitu $b_1^* = \frac{\sum x_i(y_i - b_0)}{\sum x_i^2}$.

💡 APA YANG HARUS KAMU PERHATIKAN?
1️⃣
Geser b₁ ke kiri dan kanan — lihat J naik di kedua arah dari titik minimum. Ini adalah convexity!
2️⃣
Perhatikan panah biru (gradient) — arahnya selalu menunjuk "mendaki". GD bergerak berlawanan arah ini.
3️⃣
Ubah b₀ fixed — kurva bergeser vertikal dan minimum b₁ berubah. Dua parameter saling mempengaruhi! Inilah kenapa kita perlu optimasi 2D (sub-tab berikutnya).
🗺️ LANGKAH 2 — OPTIMASI 2 PARAMETER SEKALIGUS

Sekarang kita ubah b₀ dan b₁ bersamaan. Setiap kombinasi (b₀, b₁) menghasilkan satu nilai J — ditampilkan sebagai warna di peta 2D dan tinggi di permukaan 3D. Titik putih = posisimu, titik hijau = minimum global (OLS).

Grafik 2D dan 3D selalu sinkron — geser slider atau klik peta 2D, keduanya update bersamaan.

🔑 DARI 1D KE 2D — APA YANG BERUBAH?

Di sub-tab sebelumnya, kurva J(b₁) adalah potongan melintang dari permukaan ini (satu garis horizontal di peta 2D). Sekarang kita lihat seluruh permukaan sekaligus:

$$J(b_0, b_1) = \frac{1}{n}\sum_{i=1}^{n}(y_i - b_0 - b_1 x_i)^2$$

Permukaan ini berbentuk "mangkuk" (elliptic paraboloid) — convex di semua arah. Artinya hanya ada satu minimum global, tidak ada local minima yang bisa menjebak.

🔍 NON-GRADIENT OPTIMIZER

Tidak semua fungsi loss bisa diturunkan. Kadang kita butuh optimizer yang tidak perlu gradient — hanya evaluasi nilai J di berbagai titik. Titik-titik yang dievaluasi juga muncul di peta Loss Plane secara real-time.

Grid Search

Bagi ruang parameter jadi grid N×N. Evaluasi semua sel secara sistematis. Exhaustive — tidak melewatkan minimum jika grid cukup halus.

✅ Tidak butuh gradient ⚠️ O(N²) evaluasi ❌ Buruk dimensi tinggi
Random Search

Sample titik secara acak, simpan yang terbaik. Lebih efisien dari Grid Search untuk dimensi tinggi (Bergstra & Bengio, 2012).

✅ Parallelizable ✅ Efisien dimensi tinggi ⚠️ Tidak ada garansi optimal
📐 ALGORITMA GRID SEARCH
INPUT: batas b₀, b₁, grid size N
FOR i=0..N-1, j=0..N-1:
b₀ = b₀_min + (i+0.5)×(b₀_max-b₀_min)/N
b₁ = b₁_min + (j+0.5)×(b₁_max-b₁_min)/N
J = MSE(b₀, b₁) → simpan jika terbaik
RETURN (b₀_best, b₁_best)

🐝 PARTICLE SWARM OPTIMIZATION

PSO terinspirasi dari kawanan burung mencari makanan. Setiap partikel = satu kandidat (b₀, b₁), dibimbing oleh pengalaman pribadi terbaik (pBest) dan terbaik seluruh kawanan (gBest). Tidak butuh gradient sama sekali.

🐦
Partikel = kandidat solusi (b₀, b₁)
📍
pBest = posisi terbaik partikel ini sendiri
🏆
gBest = terbaik seluruh kawanan

Velocity = arah dan kecepatan gerak
⚡ MEKANISME MATEMATIKA PSO
1 / 6
1
State setiap partikel i pada iterasi t
$$\mathbf{x}_i^t = (b_0^i,\, b_1^i) \quad\text{posisi} \qquad \mathbf{v}_i^t = (v_{b_0}^i,\, v_{b_1}^i) \quad\text{kecepatan}$$
Setiap partikel punya posisi (solusi kandidat) dan kecepatan (arah gerak). Keduanya di-update setiap iterasi.
2
Update kecepatan — 3 komponen
$$\mathbf{v}_i^{t+1} = \underbrace{w \cdot \mathbf{v}_i^t}_{\text{inersia}} + \underbrace{c_1 r_1 (\text{pBest}_i - \mathbf{x}_i^t)}_{\text{kognitif}} + \underbrace{c_2 r_2 (\text{gBest} - \mathbf{x}_i^t)}_{\text{sosial}}$$
$w$=inertia (momentum)  |  $c_1$=tarik ke pBest sendiri  |  $c_2$=tarik ke gBest kawanan  |  $r_1,r_2\sim U(0,1)$=random
3
Update posisi
$$\mathbf{x}_i^{t+1} = \mathbf{x}_i^t + \mathbf{v}_i^{t+1}$$
Sederhana! Tidak ada turunan, tidak ada gradient. Posisi baru = posisi lama + kecepatan baru.
4
Update pBest dan gBest
$$\text{pBest}_i \leftarrow \mathbf{x}_i^{t+1} \text{ jika } J(\mathbf{x}_i^{t+1}) < J(\text{pBest}_i)$$
$$\text{gBest} \leftarrow \arg\min_i\, J(\text{pBest}_i)$$
Setiap partikel mengingat posisi terbaiknya. gBest = terbaik dari semua pBest.
5
Efek hyperparameter w (inertia)
$w$ besar ≈1.0 → partikel bergerak liar, eksplorasi luas
$w$ sedang ≈0.7 → keseimbangan eksplorasi & eksploitasi
$w$ kecil ≈0.3 → konvergen cepat, bisa terjebak local optima
